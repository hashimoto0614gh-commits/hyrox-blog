HYROXは8種目＋8kmラン。シューズ選びを間違えると、スレッドで滑り、ランで脚が死ぬ。俺は2026年1月の大阪大会をサブ80（メンズオープン）で完走するまでに、3モデルを履き比べてきた。その結果、「全種目を一足でこなせる基準」がようやく見えた。結論から言う。グリップとクッション、この2つを妥協した瞬間にレースは崩壊する。

<!-- H2① -->
## HYROXのシューズ選びがランニングと根本的に違う理由

普通のマラソンシューズを選ぶ感覚でHYROXに臨むと、確実に後悔する。

マラソンなら「軽さ」と「反発」だけ追えばいい。だがHYROXには8種目のファンクショナルワークステーションがある。スレッドプッシュで152kgを押す足元にはグリップが要る。ロクサーで20kgのバッグを引きずるとき、ソールがツルツルなら体幹で踏ん張れない。ウォールボールでスクワットを繰り返すとき、クッションが薄すぎれば膝が終わる。

つまりHYROXのシューズには「矛盾する要求」が同時に突きつけられる。

- **グリップ**: スレッドプッシュ/プルで床を確実に掴む
- **クッション**: 累計8kmのランで脚を守る
- **安定性**: ロクサー、ウォールボール、ランジで足元がブレない

この3つを一足で満たせるかどうか。それがHYROXシューズ選びの核心だ。

<!-- H2② -->
## シューズに求める5機能を優先順位で並べる

俺が大阪大会サブ80を達成するまでに痛感した優先順位はこうだ。

### 1位：グリップ（すべりにくさ）

最優先。スレッドプッシュで足が滑った瞬間、パワーが地面に伝わらなくなる。152kgのスレッドを押すのに上半身の力だけでは無理だ。足裏が床を掴んでいる前提で、全身の連動が成立する。ここが弱いシューズは、どれだけ軽くても選択肢から外れる。

### 2位：クッション性

8kmのラン区間は、ワークステーションの疲労が蓄積した状態で走る。フレッシュな脚で走る8kmとは次元が違う。特に後半4kmは脚がコンクリートを叩いている感覚になる。クッションが薄いレーシングフラットで走ると、膝と足底筋膜に確実にダメージが来る。

### 3位：安定性（フィット感）

ロクサー、ウォールボール、バーピーブロードジャンプ。横方向の動きや急な切り返しが入る種目では、足がシューズの中で泳ぐと力が逃げる。ヒールカウンターの剛性と、ミッドフットのホールド感が重要だ。

### 4位：重量

軽いに越したことはないが、グリップとクッションを犠牲にしてまで軽さを追う必要はない。200g台前半なら十分だ。

### 5位：反発（カーボンプレート）

カーボンプレート搭載モデルは確かにラン区間で武器になる。だがHYROXでは「反発があるから速い」よりも「グリップがあるから崩れない」のほうが最終タイムに効く。反発は「あれば嬉しい」レベルだ。

## 実走レビュー｜俺が履き比べた3モデル

### PUMA Deviate Nitro 2 ― HYROX公式パートナーの実力

<!-- [Cocoon] 星評価ブロック: 総合4.5 -->

| スペック | 数値 |
|----------|------|
| 重量 | 261g（27.0cm） |
| ドロップ | 8mm |
| スタックハイト | 37mm / 29mm |
| ミッドソール | Nitro Elite（PEBA）+ Nitro Foam |
| アウトソール | PUMAGRIP ATR |
| プレート | カーボン（PWRPLATE） |
| 価格帯 | 約21,000円 |

PUMAはHYROXの公式パートナーだ。つまりDeviate Nitro 2は「HYROXのために作られたシューズ」ではないが、HYROX競技者が最も手に取りやすいモデルと言える。

**ラン区間**: Nitro Eliteフォームの反発が心地いい。カーボンプレートの推進力で、疲労した後半のラン区間でもストライドが維持できた。クッションも十分で、8km走り切っても膝に来なかった。

**スレッドプッシュ**: PUMAGRIP ATRのアウトソールが効いている。大阪大会の会場でスレッドを押したとき、足が滑る感覚は一切なかった。これが最大の収穫だ。

**ロクサー・ウォールボール**: ヒールカウンターの剛性が高く、横方向の安定感がある。スクワット動作で踏ん張れる。

**弱点**: 261gはこの3モデルの中で最重量。ラン区間だけを見れば、もっと軽いモデルのほうが有利だ。だがHYROXはランだけの競技ではない。

### Saucony Endorphin Speed ― 安定感とグリップのバランサー

<!-- [Cocoon] 星評価ブロック: 総合4.0 -->

| スペック | 数値 |
|----------|------|
| 重量 | 233g（27.0cm） |
| ドロップ | 8mm |
| スタックハイト | 36mm / 28mm |
| ミッドソール | PWRRUN PB |
| アウトソール | パフォーマンスラバー |
| プレート | ナイロン |
| 価格帯 | 約19,800円 |

Endorphin Speedはカーボンではなくナイロンプレート。その分、足裏の接地感が自然で、ファンクショナルワークステーションでの安定性が高い。

**ラン区間**: PWRRUN PBフォームの反発は悪くない。カーボンほどの推進力はないが、8kmを安定したペースで刻むには十分だ。

**スレッドプッシュ**: グリップは良好。ただしPUMAGRIP ATRと比べると、濡れた床面ではわずかに差を感じる場面があった。

**ロクサー・ウォールボール**: ナイロンプレートのしなりが効いて、スクワット動作との相性がいい。カーボンプレートの剛性が邪魔になる場面がない分、ファンクショナル種目ではこちらのほうが動きやすい。

**弱点**: ラン区間の推進力はDeviate Nitro 2やEndorphin Proに劣る。純粋な走力で勝負するならこのモデルではない。

### Saucony Endorphin Pro ― 最速を狙うレーサー

| スペック | 数値 |
|----------|------|
| 重量 | 218g（27.0cm） |
| ドロップ | 8mm |
| スタックハイト | 40mm / 32mm |
| ミッドソール | PWRRUN HG + PWRRUN PB |
| アウトソール | PWRTRAC |
| プレート | カーボン |
| 価格帯 | 約29,700円 |

218gは圧倒的に軽い。カーボンプレートの反発力も3モデル中トップだ。ラン区間だけなら最強の選択肢である。

**ラン区間**: 文句なし。カーボンプレートの推進力で、疲労した脚でもテンポが落ちない。ここだけを見れば最高評価だ。

**スレッドプッシュ**: ここが問題だ。スタックハイト40mmの高さは、スレッドを押すときに重心が不安定になる。アウトソールのPWRTRACは薄く、グリップ力はDeviate Nitro 2に明確に劣る。

**ロクサー・ウォールボール**: スタックの高さが仇になる。スクワット動作で足首がグラつく感覚がある。レーシングシューズの宿命だ。

**弱点**: HYROX用途としてはオーバースペックかつアンダースペック。ランは速いがワークステーションで不安定。価格も29,700円と最も高い。ラン区間のタイムを極限まで削りたい上級者向けだ。

## 深夜トレでも履きたくなるデザインの話

<!-- [Cocoon] 吹き出しブロック開始 -->

正直に言う。仕事が終わって22時にジムに向かうとき、モチベーションの半分はギアのデザインで決まる。

Deviate Nitro 2の白ベースにレインボーカラーが入ったモデルを選んだのは、まさにこの理由だ。疲れた夜でもシューズラックからこいつを手に取ると、「今日も走るか」というスイッチが入る。黄色のアクセントカラーが入ったモデルも気に入っている。

PUMAはHYROXの公式パートナーだからこそ、レースの空気感がデザインに宿っている。Sauconyのシューズも性能は申し分ないが、「HYROXのために履いている」という一体感はPUMAが一枚上だ。

<!-- [Cocoon] 吹き出しブロック終了 -->

ギアの選び方は経営と同じだ。ROIだけで判断すると、チームのモチベーションを見落とす。シューズもスペックだけで選ぶと、継続するための「感情のフック」を見落とす。特に仕事と育児の隙間で練習時間を捻出しているパパアスリートにとって、ギアのデザインは「サボらない仕組み」の一部だ。

## パパアスリートへの結論｜最初の一足はこれを買え

結論。**PUMA Deviate Nitro 2**。これが一足目だ。

理由は3つ。

1. **グリップとクッションが両立している**。HYROXで最も重要な2機能を、一足で満たしている。スレッドで滑らない。ランで脚が死なない。この安心感が初レースでは何より大きい。
2. **HYROX公式パートナーの信頼性**。PUMAはHYROXとグローバルパートナーシップを結んでいる。大会会場でPUMAブースがあり、試し履きもできる。初心者が「何を選べばいいかわからない」状態で最もリスクが低い選択肢だ。
3. **約21,000円という価格帯**。Endorphin Proの29,700円と比較して約8,000円安い。パパアスリートの財布事情を考えれば、この差は大きい。浮いた8,000円で子どもとの外食1回分が捻出できる。

迷っている時間があるなら、その30分でスクワットを10セットやったほうがタイムは縮まる。シューズは「最適解」ではなく「確実に後悔しない一足」を選べ。Deviate Nitro 2はその条件を満たしている。

## まとめ

- **HYROXのシューズ選びで最も重要なのは「グリップ」と「クッション」だ**。反発や軽さは二の次。スレッドで滑らず、ランで脚を守れるかどうかが全種目のタイムに直結する。
- **3モデル比較の結果、全種目のバランスではPUMA Deviate Nitro 2が最も安定している**。Endorphin Proはラン特化、Endorphin Speedは安定性重視。用途で使い分けるのが理想だが、一足で完結させるならDeviate Nitro 2だ。
- **パパアスリートの一足目はDeviate Nitro 2で決まりだ**。21,000円の投資で、初レースの不安を最小化できる。まずはこの一足でHYROXを完走しろ。
